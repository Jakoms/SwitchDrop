# SwitchDrop

**Файловый менеджер и передача игр на Nintendo Switch через DBI для macOS.**

Открывает файлы консоли, принимает файлы и папки из Finder и отправляет игровые пакеты через одну постоянную USB MTP-сессию. Интерфейс на русском и английском; переключение кнопкой **RU / EN** с иконкой глобуса.

[Скачать приложение](https://github.com/Jakoms/SwitchDrop/releases/latest) · [English](README.md)

## Как пользоваться

1. Распакуйте ZIP из Releases и перенесите `SwitchDrop.app` в «Программы». Нужны Apple Silicon и macOS 13 или новее. Библиотеки встроены — устанавливать Homebrew для работы не нужно.
2. Полностью завершите OpenMTP и Android File Transfer, если они запущены.
3. На Switch откройте **DBI → Run MTP responder / Запустить MTP соединение** и подключите консоль USB-кабелем с передачей данных.
4. Откройте SwitchDrop. При необходимости нажмите **«Подключиться»**. После отключения и повторного подключения кабеля новая MTP-сессия открывается автоматически, без перезапуска приложения. Кнопка «Подключиться» проверяет существующую сессию и восстанавливает зависшее соединение.

Сборка подписана локальной ad-hoc подписью и не нотариализована Apple. При первом запуске macOS может потребовать «Всё равно открыть» в настройках конфиденциальности и безопасности. Отключать системную защиту не требуется.

## Вкладка «Файлы»

Выберите хранилище. Папки открываются двойным нажатием; путь сверху позволяет вернуться назад. Поиск фильтрует текущую папку.

- Перетащите из Finder файлы или папки в таблицу либо на строку нужной папки. Они будут скопированы на SD-карту.
- «Скачать» сохраняет выбранный файл на Mac. Двойное нажатие на файл также открывает диалог скачивания.
- Доступны создание папок, переименование и удаление файлов и папок со всем содержимым — через кнопки и контекстное меню.
- Перед удалением приложение считает файлы, папки и их объём и показывает подтверждение. До подтверждения ничего не удаляется. Затем содержимое проверяется ещё раз; при изменениях нужно подтвердить заново. Корзины нет. Остановка удаления не восстанавливает уже удалённые файлы.

Изменение файлов разрешено только в **SD Card**. Остальные доступные хранилища открываются для чтения и скачивания. Набор хранилищ задаёт DBI.

Существующие файлы не перезаписываются автоматически. Если имя занято, сначала переименуйте файл или выберите другую папку. Символические ссылки не загружаются. При ошибке загрузки папки уже скопированные файлы могут остаться на консоли.

## Вкладка «Установка игр»

Добавьте NSP / NSZ / XCI / XCZ и нажмите «Передать». Пакеты отправляются последовательно в виртуальное хранилище **SD Card Install**; установкой занимается DBI. Итог установки проверяйте на экране консоли. Копирование пакета в обычную папку через вкладку «Файлы» его не устанавливает.

Очередь сохраняется между запусками. Ошибка останавливает текущую партию. Повтор начинается с начала файла; автоматического повтора и возобновления с байтового смещения нет. Переподключение восстанавливает сессию и браузер, но не запускает заново прерванную передачу или удаление. Отмена ждёт ответа DBI и может быть не мгновенной.

Поддерживаются 64-битные размеры, включая файлы больше 4 ГБ. NSZ/XCZ после установки могут занимать больше места, чем исходный файл. Приложение препятствует автоматическому сну во время передачи, но не закрытию крышки или ручному сну.

Пока не реализованы скачивание папок целиком, перенос файлов между папками консоли и установка в NAND. Одновременно используется первая доступная консоль Nintendo MTP.

## Сборка и исходники

Нужны Xcode Command Line Tools, Python 3 для тестов и pkg-config (`brew install pkgconf`):

```sh
./Source/build.sh
python3 Tests/test_backend.py
python3 Tests/test_browser.py
python3 Tests/test_adapter.py
python3 Tests/test_delete.py
python3 Tests/test_connection.py
```

Исходники libmtp/libusb включены в репозиторий. Скрипт проверяет SHA-256, собирает библиотеки для macOS 13, включает их в приложение и подписывает сборку. Интернет при сборке не нужен, если инструменты уже установлены.

Очередь: `~/Library/Application Support/SwitchDrop/queue.json`. Журнал: `~/Library/Application Support/SwitchDrop/session.log`. В журнал попадают имена файлов — проверьте его содержимое перед публикацией.
